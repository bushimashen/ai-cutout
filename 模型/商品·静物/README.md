# 商品 · 静物

**推荐模型：RMBG-1.4（见「Q版·3D·手办」目录）／备选：U²-Netp（极速轻量）**

## U²-Netp（可选，需手动准备）

- 文件名：`u2netp.onnx`（4.7 MB）
- 在线直链：**暂无国内可用直链**（HF 原站不通，`danielgatis/rembg` 镜像未同步）
- 获取方式：从 ZhengPeng7/BiRefNet的 GitHub 发布页下载（境外，可能很慢），放到本目录后上传网盘
- 擅长：边缘清楚的商品白底图 / 产品照，0.2 秒出图，模型只有 4.7MB
- 不擅长：输出偏硬边，发丝和半透明基本不行
- 授权：Apache-2.0

> 商品类主体用 RMBG-1.4 效果通常更好，U²-Netp 的价值是「小 + 快」，适合批量白底图。  
> 备好文件后：填 `assets/models.js` 的 `NETDISK.links`（id: `u2netp`），用户网盘下载 → 页面「手动上传 .onnx」。
